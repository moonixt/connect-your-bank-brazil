# Connect your Bank (Brazil)

Agent skill for free personal Open Finance in Brazil via [Meu Pluggy](https://meu.pluggy.ai) (your CPF only) + Pluggy API.

## Install

```bash
npx skills add moonixt/connect-your-bank-brazil
```

Or a specific skill path:

```bash
npx skills add moonixt/connect-your-bank-brazil --skill connect-your-bank-brazil
```

## What it covers

- Connect banks on Meu Pluggy
- Dashboard app + connector `200` (MeuPluggy)
- Demo OAuth (not direct bank connectors)
- Client ID / Secret / Item ID
- Pluggy API auth, accounts, and `/v2/transactions`

Personal free path — not the commercial multi-user Pluggy plan.
